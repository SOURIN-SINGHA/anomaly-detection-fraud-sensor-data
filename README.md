# anomaly-detection-fraud-sensor-data
ISI Internship Project: Fraud Transaction Anomaly Detection using Z-Score, IQR, Isolation Forest, and LOF.
## Overview
This project implements anomaly detection techniques on a synthetic fraud transaction dataset.

## Methods Used
- Z-Score
- IQR Method
- Isolation Forest
- Local Outlier Factor (LOF)

## Results
- Z-Score: 19 anomalies
- IQR: 54 anomalies
- Isolation Forest Precision: 0.98
- Isolation Forest Recall: 0.98
- LOF Precision: 0.22
- LOF Recall: 0.22
